## 📝 Instrucciones de Reemplazo

1. **Coloca las imágenes** en las carpetas correspondientes según la estructura anterior
2. **Mantén los nombres exactos** de los archivos para que el código funcione automáticamente
3. **Optimiza las imágenes** para web (JPG para fotos, PNG para gráficos con transparencia)
4. **Mantén las proporciones** sugeridas para mejor visualización

## 🎨 Criterios de Selección

### Estilo Visual
- **Colores**: Que complementen la paleta de Verde medianoche (#04444D) y Esmeralda (#04BA70)
- **Estilo**: Profesional, moderno, que transmita confianza y solidez
- **Calidad**: Alta resolución, bien iluminadas

### Contenido
- **Productos**: Que muestren la calidad y origen latinoamericano
- **Servicios**: Que reflejen profesionalismo y tecnología
- **Equipo**: Que transmitan cercanía y confianza humana
